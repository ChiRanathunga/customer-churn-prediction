# customer-churn-prediction

This project predicts customer churn using Machine Learning.

## Tools Used
- Python
- Pandas
- Scikit-learn

## Machine Learning Workflow
1. Data Cleaning
2. Feature Selection
3. Train/Test Split
4. Logistic Regression
5. Accuracy Evaluation

## Result
The model achieved approximately 78% accuracy.
